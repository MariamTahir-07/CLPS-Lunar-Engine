# CLPS Lunar Landing Site & Hardware Protection Engine
NASA Space Apps 2026 prototype: compares lunar south-pole candidate sites by terrain slope, terrain horizon, Sun visibility, Earth visibility, and a configurable GO/NO-GO *screening*.
**Status: demonstration mode.** Terrain is synthetic and Sun/Earth geometry is an analytic approximation. Real LOLA/SPICE paths are scaffolded but untested here (NASA hosts were unreachable). See LIMITATIONS.md.
Quick start: SETUP.md. Demo script: DEMO_GUIDE.md.
